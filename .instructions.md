# NephroPaidi Development Instructions

## Project Context
**Full Doctor Workflow System** for a nephrology clinic platform. Microservices architecture (8 services) with Spring Boot backend + Angular frontend.

## Core Principles
1. **Autonomy First**: Make decisions and proceed. Only ask for clarification on ambiguous requirements.
2. **Consistency**: Follow existing patterns. Don't create new patterns.
3. **Minimal Scope**: Implement only what's necessary. No over-engineering.
4. **Documentation**: Keep README/analysis files updated with progress.

---

- **Language**: Java 17+

## Code Patterns & Conventions

### Backend Entity Layer
```java
@Entity
@Table(name = "table_name")
@Getter @Setter
public class MyEntity {
    @Id
    @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;
    
    @Column(name = "doctor_id")
    private UUID doctorId;  // Always UUID for doctors
    
    @Column(name = "patient_id")
    private Long patientId;  // Always Long for patients
    
    @Enumerated(EnumType.STRING)
    @Column(name = "status")
    private MyStatus status;
    
    @CreationTimestamp
    @Column(name = "created_at")
    private LocalDateTime createdAt;
    
    @UpdateTimestamp
    @Column(name = "updated_at")
    private LocalDateTime updatedAt;
}
```

### Service Layer Pattern
```java
// Interface
public interface MyService {
    MyDto create(CreateRequest request, UUID doctorId);
    List<MyDto> getByDoctor(UUID doctorId);
    MyDto update(UUID id, UpdateRequest request);
}

// Implementation with logging
@Service
@Slf4j
public class MyServiceImpl implements MyService {
    private final MyRepository repository;
    
    @Override
    public MyDto create(CreateRequest request, UUID doctorId) {
        log.info("Creating MyEntity for doctor: {}", doctorId);
        MyEntity entity = MyEntity.builder()
            .doctorId(doctorId)
            .status(MyStatus.PENDING)
            .build();
        MyEntity saved = repository.save(entity);
        return convertToDto(saved);
    }
}
```

### Controller Pattern
```java
@RestController
@RequestMapping("/api/clinical/my-endpoint")
@Slf4j
public class MyController {
    
    @PostMapping
    public ResponseEntity<MyDto> create(
            @RequestBody CreateRequest request,
            @RequestHeader(value = "X-Doctor-Id", required = false) UUID doctorId,
            Authentication authentication) {
        UUID resolvedDoctorId = doctorIdResolver.resolve(doctorId, authentication);
        MyDto response = myService.create(request, resolvedDoctorId);
        return ResponseEntity.status(HttpStatus.CREATED).body(response);
    }
    
    @GetMapping("/my")
    public ResponseEntity<List<MyDto>> getMyEntities(
            @RequestHeader(value = "X-Doctor-Id", required = false) UUID doctorId,
            Authentication authentication) {
        UUID resolvedDoctorId = doctorIdResolver.resolve(doctorId, authentication);
        List<MyDto> response = myService.getByDoctor(resolvedDoctorId);
        return ResponseEntity.ok(response);
    }
}
```

### Frontend Component Pattern
```typescript
@Component({
  selector: 'app-my-component',
  standalone: true,
  imports: [CommonModule, FormsModule, ReactiveFormsModule],
  templateUrl: './my-component.html',
  styleUrl: './my-component.scss'
})
export class MyComponent implements OnInit, OnDestroy {
  loading = false;
  errorMessage = '';
  items: MyItem[] = [];
  refreshInterval: any;

  constructor(
    private http: HttpClient,
    private authService: AuthStorageService
  ) {}

  ngOnInit(): void {
    this.loadData();
    this.refreshInterval = setInterval(() => this.loadData(), 300000); // 5 min
  }

  ngOnDestroy(): void {
    if (this.refreshInterval) clearInterval(this.refreshInterval);
  }

  loadData(): void {
    this.loading = true;
    const url = `${environment.apiBaseUrl}/api/my-endpoint/my`;
    this.http.get<MyItem[]>(url).subscribe({
      next: (data) => {
        this.items = data;
        this.loading = false;
      },
      error: (err) => {
        console.error('Error loading data:', err);
        this.errorMessage = 'Failed to load data';
        this.loading = false;
      }
    });
  }
}
```

## Database Migration Rules

### Flyway Migration Naming
- Format: `V{N}__{descriptive_name}.sql`
- Examples: `V8__create_lab_requests_table.sql`, `V11__add_appointment_timestamps.sql`

### SQL Conventions
```sql
-- Always use lowercase table names with underscores
CREATE TABLE IF NOT EXISTS my_table (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    doctor_id UUID NOT NULL,
    patient_id BIGINT NOT NULL,
    status VARCHAR(50) NOT NULL DEFAULT 'PENDING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_my_table_doctor FOREIGN KEY (doctor_id) REFERENCES users(id),
    CONSTRAINT fk_my_table_patient FOREIGN KEY (patient_id) REFERENCES patients(id)
);

CREATE INDEX idx_my_table_doctor_id ON my_table(doctor_id);
CREATE INDEX idx_my_table_patient_id ON my_table(patient_id);
CREATE INDEX idx_my_table_status ON my_table(status);
```

## API Conventions

### Request/Response Pattern
```
POST /api/clinical/{resource}          → Create (returns DTO with ID)
GET /api/clinical/{resource}/my        → List mine (doctor-specific)
GET /api/clinical/{resource}/{id}      → Get single
PATCH /api/clinical/{resource}/{id}    → Update
DELETE /api/clinical/{resource}/{id}   → Delete

POST /api/clinical/{resource}/{id}/action → Custom action
```

### Status Codes
- `201 Created` → POST successful
- `200 OK` → GET/PATCH successful
- `400 Bad Request` → Invalid input
- `401 Unauthorized` → Not authenticated
- `403 Forbidden` → No permission
- `404 Not Found` → Resource doesn't exist
- `500 Internal Server Error` → Unexpected error

### DTO Pattern
```java
@Data
@Builder
public class MyDto {
    private UUID id;
    private UUID doctorId;
    private Long patientId;
    private String status;
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}

@Data
public class CreateRequest {
    @NotNull
    private Long patientId;
    
    @NotBlank
    private String description;
    
    @NotNull
    @Pattern(regexp = "URGENT|ROUTINE")
    private String urgency;
}
```

## Decision Rules

### When to Create New Microservice
- If the feature handles a completely different business domain (unlikely)
- Otherwise: Add to `clinical-service`

### When to Modify vs Create Entities
- If the field belongs to an existing entity → Add column via Flyway migration
- If it's a new concept → Create new entity + migration

### When to Ask vs Proceed
**ASK** if:
- Requirements contradict each other
- Scope impacts deployment/timeline significantly

**PROCEED** if:
- Implementation approach is clear
- Pattern exists elsewhere in codebase
- Low risk of breaking existing features

## Troubleshooting
- **Import errors**: Check package path spelling (e.g., `security` vs `util`)
- **Method not found**: Check existing entity/repository for actual method names
- **Compilation fails**: Run `mvn clean compile -q` to see error summary
- **Frontend errors**: Check environment.ts for correct property names (apiBaseUrl, NOT apiUrl)
- **Type errors in TS**: Use `as FormArray`, `as FormGroup` for type casting when needed
